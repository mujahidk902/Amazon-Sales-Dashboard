# 📦 Amazon Sales Dashboard – Power BI

## 📊 Project Overview
An interactive Power BI dashboard analyzing Amazon sales performance,
trends, and key business metrics.

## 🔍 Key Insights
- Total Revenue & Units Sold
- Top-performing Categories & Products
- Monthly/Quarterly Sales Trends
- Regional Sales Breakdown

## 🛠 Tools Used
- Power BI Desktop
- Microsoft Excel / CSV (Data Source)
- DAX for calculated measures

## 📁 Files
| File | Description |
|------|-------------|
| `AMAZON_SALES.pbix` | Main Power BI report file |
